== Recurring datasets

The Beijing Multi-Site Air Quality snapshot is the semester spine. AI4I 2020 supplies a compact industrial classification context, Dry Bean is a reserve multiclass dataset, and versioned synthetic generators provide mathematical oracles. No normal class activity or assessment depends on a live download.

== Optional extension routes

The extension section sits outside the fourteen scheduled blocks. Students may select JAX transformations, kernel methods, probability calibration, DuckDB/Polars comparison, local experiment tracking, or drift monitoring for preparation or project exploration. These routes add no required contact hours and no assessment prerequisite.

Use xref:extensions/downstream-paths.adoc[the downstream CSMI map] to carry the appropriate evidence into Scientific Machine Learning, High Performance Computing, Database, and Project courses.

== How to read the map

* *Importance* says whether a concept is required: P0 Essential, P1 Core, P2 Extension, or P3 Deferred.
* *Difficulty* says how independently it must be used: D1 Guided, D2 Independent, or D3 Synthesis.
* xref:assessment/overview.adoc[Assessment design] shows where evidence is graded.
* xref:technical-contract.adoc[Execution contract] fixes the supported hardware, runtime, and tolerance rules.
* xref:readiness-check.adoc[Readiness check] provides the entry diagnostic and remediation route.
