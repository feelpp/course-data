The course contains fourteen two-hour blocks. Essential (P0) and Core (P1) material is the course requirements: it is taught, practised, and assessed. Extension (P2) demonstrations are optional and cannot be required in a control or examination.

Use the block guide below for the teaching sequence. Page-duration labels describe complete reference and practice routes; they are not additional contact hours. Each block below totals 120 minutes, including its stated activities. The final examination is separate from these 28 contact hours.

== Learning Python and pandas together

No pandas experience is required at entry. Block 2 follows xref:foundations/python-pandas.adoc[Python refresher and first steps with pandas]: the same four-sensor table as the first class, predictions by hand, short code cells, and time to explain. Block 3 follows xref:foundations/pandas-sql.adoc[grouping, joins, and the SQL bridge]. Block 4 introduces array shapes and reshaping, then practises them during EDA. The full xref:foundations/tabular-data.adoc[tabular reference] supports this progression; reading it in advance is not required.

If the first operations remain unclear, use the recap and targeted support before independent tasks. The xref:readiness-check.adoc[readiness check] identifies support needs; it has no entry score. The SQL demonstration establishes the connection to the Database course; query performance remains in Block 12.

== Preparation and mathematical support

Before Block 4, spend at most 20 minutes revisiting your audit report and one pandas selection/grouping example. Bring a limitation and a question. The xref:foundations/statistical-exploration.adoc[5 October notebook] introduces statistics when the investigation needs them, with links to the existing mathematical definitions and short examples.

We describe empirical distributions and associations in Block 4, introduce sampling limitations there and use the xref:foundations/eda-sampling.adoc[sampling companion] before Block 5. Mean/quantile uncertainty remains later support. We revisit vectors and conditioning in Block 6, and use xref:foundations/probability-distributions-moments.adoc[probability models and moments] for likelihood and classification in Blocks 6–7. Complete chapters remain available for support and further practice. The diagnostic guides additional individual support.

The assigned preparation totals 325 minutes across the semester. Practice and project production are separate from this preparation budget. If an activity takes longer, use the indicated support route and report the difficulty; contact time does not expand to absorb every reference-page estimate.

The 65-minute documentation/testing activity E12 is distributed across Blocks 2 (15), 3 (10), 5 (10), 7 (10), and 12 (20). Tests, provenance, and assistance disclosure are therefore practised before Control 1. Block 12 consolidates them while measuring a columnar workflow.

E08 belongs to Block 9. E14 is the 55-minute audit inside Control 2, not another 55-minute task. Individual project verification uses a separately announced appointment, with 5–8 minutes per student plus transitions; it is not placed in the spare minutes of Block 14.

== Required depth

Students implement and validate a small pipeline search before the Block 13 clinic. The project starts from a question and baseline in Block 5 and develops as methods are taught. Required tree/forest work includes fitting and comparison; boosting includes interpreting its objective and supplied comparison. For hierarchical clustering and DBSCAN, run the supplied geometry comparison and explain assumptions, parameters, and failure cases. Implementing those algorithms from scratch is outside the assessed scope.

== Recurring datasets

Block 2 reuses the four-sensor temperature table from the first class. Block 3 adds a second time for those same sensors. From Block 4, the Beijing Multi-Site Air Quality snapshot is the semester spine. AI4I 2020 supplies a compact industrial classification context, Dry Bean is a reserve multiclass dataset, and versioned synthetic generators provide mathematical oracles. No normal class activity or assessment depends on a live download.

== Optional extension routes

The extension section sits outside the fourteen scheduled blocks. Students may select JAX transformations, kernel methods, probability calibration, DuckDB/Polars comparison, local experiment tracking, or drift monitoring for preparation or project exploration. These routes add no required contact hours and no assessment prerequisite.

Use xref:extensions/downstream-paths.adoc[the downstream CSMI map] to connect this work to Scientific Machine Learning, High Performance Computing, Database, and Project courses.
