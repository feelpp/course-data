This two-hour session is for CSMI master's students who already know Python and are discovering pandas. We start with the four-sensor table from the first class and connect table operations to mathematical questions about means, weights and dimensions.

== Working alongside the slides

Use the green *Download bundle* button and follow xref:environment.adoc[Computing environment: install uv, create a virtual environment and open the notebook in VS Code]. The bundle supplies `pyproject.toml` and `uv.lock`; `uv sync --locked` installs the required libraries. The four corresponding notebooks are available from each page's download toolbar. Open notebooks inside the extracted bundle so the air-quality examples can find their data.

Students whose environment is not ready can work in pairs and follow the demonstrations. Keep the original sensor values, create a separate Celsius column, and report both the mean and the number of available readings. The xref:foundations/python-pandas.adoc#_practise_on_the_same_table[first short exercise] changes only one reading.
