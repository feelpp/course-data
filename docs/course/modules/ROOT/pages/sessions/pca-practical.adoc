== 2. Calculate directions, scores and variance — 12 minutes

A principal *direction* has p coefficients, one per input variable. A *score*
is the coordinate of one observation on that direction; one component has n
scores. Use an economy SVD of stem:[A_z] with `full_matrices=False`.
NumPy returns `U`, `singular` and `Vt`, where `Vt` is the transpose of the
direction matrix V. Determine which orientation gives directions as columns.

For component j, its sample variance is the squared singular value divided
by n−1. Its explained variance ratio divides that variance by the sum of all
component variances. The cumulative ratio adds the ratios of the first k
components. Here k is the number of retained directions.

----

# Check nonnegative variances, ratios summing to one, orthonormal directions.

Before running, state the expected shapes. After running, check them and
compare score variances with your calculated component variances. Explain
why directions and scores have different numbers of entries.

[%collapsible]
.Optional hint 2 — transpose the direction matrix, not the observations
====
For this table n is larger than p. Economy SVD therefore returns U of shape
(n, p), singular of shape (p,), and Vt of shape (p, p). NumPy stores directions
as *rows* of Vt; your variable directions must store them as *columns*.
The projected table must still have one row per observation. Check that the
inner dimensions of each matrix product agree before calculating it.
====

*Checkpoint 2 — before plotting.* For this table, directions has shape
(p, p) and scores has shape (n, p). A single direction has p coefficients;
one component has n scores. Check that directions have unit length and are
mutually orthogonal. Score means should be close to zero; each score column's
sample variance should match the corresponding calculated variance. The
ratios should sum to one, within rounding. If they do not, repair this step
before drawing a figure.

[%collapsible]
.Optional hint 3 — return from component coordinates to variable coordinates
====
The first k score columns form an n-by-k table. The first k direction columns
form a p-by-k table. Find the transpose that makes their product n-by-p:
each reconstructed cell must correspond to an original row and variable.
Check the error in standardized coordinates before changing any units.
To recover physical values afterwards, multiply each reconstructed column
by its original sample standard deviation, then add its original mean.
That last conversion is optional today.
====
