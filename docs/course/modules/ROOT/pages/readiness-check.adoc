Complete this individual preparation check before Block 2. It carries no mark and has no passing score. Having never used pandas is an expected starting point: the xref:foundations/python-pandas.adoc[first Python–pandas session] teaches it in class.

Spend at most 35 minutes: environment 10, Python 7, arrays 5, table reasoning 8, and mathematics 5. Stop when time is up and bring unfinished items. For each topic, record *independent*, *with help*, *not yet encountered*, or *blocked*, plus one answer or question. Do not use generative AI for this inventory; documentation is allowed. The purpose is to show what support would help you.

== A. Environment — attempt, then record the result

. Download the student bundle using the green *Download bundle* button or xref:downloads.adoc[the downloads page]. Extract it into a new folder and follow xref:environment.adoc[the Python setup]. No repository clone or npm installation is required. From the extracted folder, try:
+
[source,shell]
----
uv sync --locked
uv run python -c "import numpy, pandas; print(numpy.__version__, pandas.__version__)"
----
. Open `notebooks/foundations/python-pandas.ipynb` using the extracted folder's `.venv` kernel. Restart the kernel and run the supplied cells in order. The practice prompts will be completed in class; running the examples is enough for this setup check.
. Record the version output and whether the run completes. If something fails or installation exceeds ten minutes, keep the error message, mark *blocked*, and continue with B–E. You may answer those on paper.

A successful fresh-kernel run is needed before independent notebook work. A setup blocker does not prevent attending the guided session: use the rendered page or work with a partner, then arrange installation support. We explain the lockfile and hidden notebook state together in class.

== B. Python — what is already familiar?

Given the code below, predict the first printed value. Explain what the dictionary represents and what the function would return (if functions are familiar). If these constructs are new, identify the unfamiliar ones; you do not need to learn them alone before class.

[source,python]
----
values = [22.0, 71.6, 20.0, None]
record = {"sensor": "A", "temperature": values[0], "unit": "°C"}


def fahrenheit_to_celsius(value):
    return (value - 32) * 5 / 9


print(values[0])
print(fahrenheit_to_celsius(71.6))
----

Variables, lists, dictionaries, calculations, imports, and reading errors are revisited in Block 2. A function example is provided for later practice.

== C. Arrays — an exposure question

Have you used NumPy? Can you explain what “four rows and three columns” means and identify a shape `(4, 3)`? Have you encountered a Boolean mask or broadcasting? Record your experience and one uncertainty; do not implement these operations now.

Shapes and column operations are introduced in Block 4 and revisited before their use in Block 6. NumPy fluency is not an entry requirement for the first pandas session.

== D. Tables — reason on paper first

Return to the four-sensor table from the first class, at the same stated time:

[cols="1,1,1",options="header"]
|===
|Sensor |Recorded temperature |Unit
|A |22 |°C
|B |71.6 |°F
|C |20 |°C
|D |Missing |°C
|===

. What does one row represent? What identifies a reading?
. How many records and how many available temperatures are there?
. Which unit needs conversion before computing a mean? Why is a missing value different from zero?
. Have you used pandas to represent or manipulate a table? Record your experience separately from the paper answers.

No pandas code, grouping, join, or reshape is required here. Blocks 2–3 teach those first table operations; reshaping follows in Block 4.

== E. Mathematical notation — identify a support need

Explain a scalar, vector, or matrix in your own words. Compute the mean of `[1, 2, 3]`; if familiar, also compute its population variance. Mark any unfamiliar notation or calculation for the mathematical support route. This is a short inventory, not a prerequisite examination.
