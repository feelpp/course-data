Complete this individual check before Block 2. It is diagnostic, carries no mark, and is designed to identify the shortest useful preparation route. Record commands, answers, and any error messages in one file.

== Rules and scoring

Allow 35 minutes without external AI assistance. Documentation for Python, NumPy, and pandas is allowed. Score each of the five domains out of four. The general readiness threshold is 15/20, but the environment domain requires 4/4. A low score is a routing signal, not a judgement about your ability to complete the course.

== A. Environment and reproducible execution — 4 points

. Download the student bundle using the green *Download bundle* button or xref:downloads.adoc[the downloads page]. Extract it into a new folder and follow xref:environment.adoc[the Python setup]. No repository clone or npm installation is required. From the extracted folder, run:
+
[source,shell]
----
uv sync --locked
uv run python -c "import numpy, pandas; print(numpy.__version__, pandas.__version__)"
----
. Open `notebooks/foundations/data-lifecycle.ipynb` using the extracted folder's `.venv` kernel. Restart the kernel and run all cells in order. Record the version output and whether the notebook completes; preserve any error messages.
. Explain what the Python lockfile fixes and what restarting and running every cell checks that saved notebook output does not.

Award one point for successful environment installation and the version output, one point for the notebook completing from a fresh kernel, and two points for the explanation: one for dependency identity and one for hidden state. Total: four points. If installation takes longer than the diagnostic session, record the obstacle and continue with B–E; complete A through the environment support route.

== B. Core Python — 4 points

Write a function `summarise(values)` that accepts numbers and `None`, returns the count of valid values and their arithmetic mean, and raises a clear exception when no valid value exists. Demonstrate it with one ordinary case and the empty-valid-data case.

== C. NumPy arrays — 4 points

Given `x = np.arange(12).reshape(4, 3)`:

. state its shape and dtype;
. select the rows whose first column is at least 6 without a Python loop;
. subtract each column mean using broadcasting;
. explain the shape of the mean used for broadcasting.

== D. Tabular reasoning — 4 points

Construct a small DataFrame with columns `station`, `timestamp`, `variable`, and `value`. Then:

. identify the unit of analysis;
. detect duplicate `(station, timestamp, variable)` keys;
. calculate the mean value by station and variable;
. reshape the result so variables become columns without silently aggregating duplicate keys.

== E. Mathematical and quantitative reasoning — 4 points

. Explain the difference between a scalar, a vector, and a matrix using shapes.
. Compute the mean and population variance of `[1, 2, 3]`.
. Explain why stem:[\log(ab)=\log(a)+\log(b)] helps when multiplying many small probabilities.
. State one reason a predictive association is not automatically a causal effect.
