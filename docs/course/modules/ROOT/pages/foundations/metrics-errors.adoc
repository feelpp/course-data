A metric compresses consequences; it does not define them. Select the metric and decision threshold from the use, prevalence, scale, and costs before comparing many models.

== Regression

MAE is in target units and treats deviations linearly. RMSE penalises large residuals more strongly and is sensitive to scale/extremes. Always compare with a constant baseline and inspect residuals by predicted value, time, group, and relevant operating range. A lower aggregate error can hide systematic failure for one station or regime.

== Classification

The confusion matrix contains the operational counts. Precision conditions on predicted positives; recall conditions on actual positives; F1 encodes one symmetric trade-off. ROC-AUC ranks across thresholds but can look reassuring under severe imbalance; PR-AUC focuses on the positive class and must be compared with prevalence. Neither AUC selects the deployment threshold.

Choose a threshold using missed-event cost, false-alarm workload, or an explicit constraint. Do not tune the threshold on the final test. A score is not automatically a calibrated probability.

== Independent transfer

Write a two-paragraph recommendation for a maintenance team with limited inspection capacity and high missed-failure cost. State the chosen metric/threshold evidence, expected false alarms and misses on the evaluation sample, one subgroup/failure pattern, uncertainty or sampling limitation, and why the synthetic dataset is not factory validation.

== Acceptance criteria

Metrics use a clearly named positive class; confusion-matrix orientation is explicit; baseline and model use identical cases; threshold selection is separated from final evaluation; interpretation reports counts as well as rates and avoids causal claims.
