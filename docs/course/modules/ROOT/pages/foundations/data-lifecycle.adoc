A reliable analysis starts before modelling. First define what one row represents, where the data came from, what may be missing or duplicated, and which values are impossible.

.Definition: Estimand and estimate
[.def#def:lifecycle-estimand]
****
An *estimand* is the population quantity stem:[\theta(P)] that answers the stated question. An *estimate* stem:[\widehat\theta(\mathcal D)] is the value computed from observed data stem:[\mathcal D]. The distinction forces three early questions: what is the target population stem:[P], how was stem:[\mathcal D] obtained, and which transformations connect the raw records to stem:[\widehat\theta]?
****

Read xref:foundations/mathematical-background.adoc[Mathematical background and error estimation] before the first modelling chapter; it defines the notation used across the site.

== Audit sequence

. State the decision or scientific question.
. Define the unit of analysis and the target population.
. Record the source, licence, retrieval time, and checksum.
. Validate the schema, types, units, categories, and timestamps.
. Quantify missing values and duplicates.
. Test domain constraints and investigate anomalies.
. Save the audit as executable checks, not only prose.

== First error ledger

Before calculation, list at least one possible data, sampling, modelling, numerical, and communication error. A useful analysis records the transformation chain

[stem]
++++
\mathcal D_{\mathrm{raw}}
\xrightarrow{\text{validate/repair}}
\mathcal D_{\mathrm{analysis}}
\xrightarrow{\text{method}}
\widehat\theta
\xrightarrow{\text{report}}
\text{decision claim}.
++++

Checks at one arrow do not validate the others. A schema-valid table can be unrepresentative; a numerically accurate estimate can answer the wrong population question.

== Worked example

.Example: Mean temperature is not yet a question
[.examp#ex:lifecycle-mean]
****
The formula stem:[\bar x=n^{-1}\sum_i x_i] is unambiguous, but its meaning is not. It may average sensor readings equally, days equally, or stations equally. Those estimands differ when groups have different numbers of rows. The unit of analysis and target population must precede the code.
****
