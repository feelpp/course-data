== Distribution summaries

Use xref:foundations/probability-distributions-moments.adoc[Probability distributions and statistical moments] for mass, density, support, and moment definitions. Use xref:foundations/quantiles-exceedance-risk.adoc[Quantiles, exceedance probabilities, and risk] for CDF inversion and tail uncertainty. This section applies their empirical counterparts during exploration.

For observations stem:[x_1,\ldots,x_n], the empirical cumulative distribution function is

[stem]
++++
\widehat F_n(t)=\frac1n\sum_{i=1}^{n}\mathbf 1\{x_i\le t\}.
++++

It preserves distributional information that a mean and standard deviation can hide. Quantiles, histograms, and box plots are summaries of the empirical distribution, not evidence that a particular parametric distribution generated the data.

.Definition: Empirical covariance and correlation
[.def#def:covariance-correlation]
****
[stem]
++++
s_{xy}=\frac1{n-1}\sum_{i=1}^{n}(x_i-\bar x)(y_i-\bar y),
\qquad
r_{xy}=\frac{s_{xy}}{s_xs_y}.
++++

Correlation measures linear association in the observed sample. It is sensitive to outliers, mixtures, time trends, and range restriction; it does not identify a causal effect.
****

== Question before figure

For every figure, write the question, population/sample, unit, grouping, scale, missing-data rule, and uncertainty or variation shown. Label axes with units. == Sampling and representativeness

The Beijing slice contains three stations and fourteen days from March 2013. It can support exercises about those recorded observations; it cannot represent all Beijing stations, seasons, current air quality, Strasbourg, or causal effects of weather. Temporal autocorrelation means hourly rows are not automatically independent. A random row split can exaggerate forecasting evidence by placing near-neighbour times in both train and test.

Let stem:[S_i=1] indicate inclusion of population unit stem:[i]. The inclusion probability stem:[\pi_i=P(S_i=1)] matters: if it varies with the measurement or relevant covariates, the unweighted sample mean need not estimate the population mean. A larger convenience sample reduces neither coverage error nor selection bias by itself.

== Error estimation

Under independent sampling, stem:[\widehat{\operatorname{SE}}(\bar X)=s/\sqrt n]. With temporal or grouped observations,

[stem]
++++
\operatorname{Var}(\bar X)=\frac1{n^2}\sum_{i=1}^{n}\sum_{j=1}^{n}\operatorname{Cov}(X_i,X_j),
++++

so positive within-group correlation makes the independent-row formula too small. Match resampling to the population claim: resample stations for a station population, days or contiguous blocks for a temporal claim, and complete subjects or machines for repeated measures. Variation across the three observed stations is not a reliable estimate of variation across all stations.

== Hand calculation: effective information under clustering

.Example: Effective information under clustering
[.examp#ex:cluster-information]
****
Suppose 24 hourly observations have standard deviation stem:[s=12]. Treating them as independent gives stem:[SE=12/\sqrt{24}\approx2.45]. If they form six four-hour blocks with within-block correlation stem:[\rho=0.5], the design effect is approximately stem:[1+(4-1)\rho=2.5], giving stem:[SE\approx2.45\sqrt{2.5}=3.87]. The point estimate is unchanged, but its claimed precision is not.
****

=== Method

*Importance:* Essential (P0)

For station stem:[s] and day stem:[d], the plotted value is stem:[\bar x_{sd}=n_{sd}^{-1}\sum_{i\in(s,d)}x_i], where stem:[n_{sd}] counts valid PM2.5 observations. The method constructs timestamps, preserves missing values, aggregates by this declared key, checks coverage, and then presents the numerical range and time pattern.

.Mathematical insight — aggregation changes the analysis unit
[IMPORTANT]
====
[.notebook-insight-label]
*Mathematical insight.*

*Essential (P0).* The daily mean gives equal weight to each valid hourly record within a station-day, while a later summary of daily means can give equal weight to days. These are different weighting rules when coverage varies. Missing hours therefore affect both uncertainty and the implicit estimand; aggregation does not make missingness disappear.
====

[.worked-example-implementation#worked-eda-implementation]
=== Implementation

*Importance:* Essential (P0)

The same `daily` table drives both the bounded numerical summary and the diagnostic figure, preventing the plotted and reported quantities from drifting apart.

[#eda-summary-table]
[%dynamic%open,python,fail-on-error=,output=table,table-caption="Station-level summary of the plotted daily PM2.5 values",table-description="Rows are stations. from pathlib import Path

import pandas as pd

# Build exactly the station-day quantity named in the worked question.
def course_file(relative: str) -> Path:
    """Locate canonical data in a repository checkout or student bundle."""
    for root in [Path.cwd(), *Path.cwd().parents]:
        candidate = root / relative
        if candidate.is_file():
            return candidate
    raise FileNotFoundError(relative)


data_path = course_file("datasets/teaching/air-quality/observations.csv")
air = pd.read_csv(data_path)
air["timestamp"] = pd.to_datetime(air[["year", "month", "day", "hour"]])
air["date"] = air["timestamp"].dt.floor("D")
daily = (
    air.groupby(["station", "date"], observed=True, as_index=False)
    .agg(pm25_mean=("PM2.5", "mean"), valid_pm25=("PM2.5", "count"))
)
assert daily["station"].nunique() == 3
assert daily["date"].nunique() == 14

# Show bounded numerical context before asking students to read the time plot.
daily.groupby("station")["pm25_mean"].agg(
    represented_days="count", minimum="min", mean="mean", maximum="max"
).round(2)
----

import matplotlib.pyplot as plt

plt.style.use("tableau-colorblind10")
fig, ax = plt.subplots(figsize=(9, 4.5), constrained_layout=True)
styles = [("-", "o"), ("--", "s"), (":", "^")]
for (station, group), (line_style, marker) in zip(
    daily.groupby("station", observed=True), styles, strict=True
):
    ax.plot(
        group["date"],
        group["pm25_mean"],
        label=station,
        linestyle=line_style,
        marker=marker,
        markersize=4,
    )
ax.set(title="Daily mean PM2.5 by station", xlabel="Date (March 2013)", ylabel="PM2.5 (µg/m³)")
ax.legend(title="Station")
ax.grid(alpha=0.25)
plt.show()
----

[.worked-example-conclusion#worked-eda-conclusion]
=== Conclusion

*Importance:* Essential (P0)

Recorded daily PM2.5 varies across stations and time in this reviewed 14-day slice, with some movements shared across stations. Agreement may reflect shared weather rather than station equivalence. These summaries describe recorded values only: they do not correct informative missingness, quantify serial dependence, or represent unobserved stations and months. Consequently they support an exploratory description, not a causal station comparison or a city-wide generalisation.
