This is the practical companion to xref:foundations/data-quality.adoc[Data quality, schemas, missingness, and anomalies]. It applies the complete audit route to a real teaching extract rather than a succession of unrelated toy tables.

The dataset contains *1,008 original hourly observations*: three Beijing monitoring stations × fourteen complete days, from 1 to 14 March 2013. It contains six air-pollution measurements, six meteorological variables, a wind category, time fields, and a station identifier. Values come from the UCI Beijing Multi-Site Air-Quality dataset and have not been statistically imputed or repaired.

Use the notebook download in the page toolbar. At every stage: predict, run, inspect, and explain. Keep the loaded tables unchanged; create new variables for derived columns and practice defects.

== The big picture

The practical follows the complete path from a released file to a limited scientific statement:

[cols="1,4",frame=none,grid=rows]
|===
|1 |*Source and manifest* — Which files are we using, where do they come from, and are they the declared release?
|↓ |
|2 |*Observation, key, and schema* — What does one row represent, which columns identify it, and what do the other columns mean?
|↓ |
|3 |*Completeness, validity, consistency, and plausibility* — Which values are absent, impossible, contradictory, or unusual enough to inspect?
|↓ |
|4 |*Analysis and denominators* — Which observations actually contribute to each comparison and summary?
|↓ |
|5 |*Audit report and limitations* — What can we conclude from this slice, what action is justified, and what remains unknown?
|===

Our working question is:

_How do PM2.5 and NO2 measurements differ across the three stations during these fourteen days, and which data-quality findings limit that comparison?_

This is a descriptive question about the released slice. It is not a claim about all Beijing stations, other seasons, current air quality, personal exposure, or causes of pollution.

== Worked example: audit the complete teaching extract

[.worked-example-context#worked-quality-practical-context]
=== Context

*Importance:* Essential (P0)

The course bundle contains three connected artifacts:

* `observations.csv`: 1,008 hourly rows and 18 columns;
* `stations.csv`: a three-row station registry;
* `MANIFEST.yml`: file identities, row counts, byte sizes, and SHA-256 checksums.

One intended observation is one station at one hour. Its key is `(station, year, month, day, hour)`. The registry relationship is many observations to one station.

The dataset is complete in the sense that the released teaching artifact contains the full declared three-station, fourteen-day grid. This does not mean that every measurement cell is present or that the slice represents the complete upstream population.

[.worked-example-method#worked-quality-practical-method]
=== Method

*Importance:* Essential (P0)

. Verify the artifact before analysing its values.
. Check row identity, time coverage, and the station registry.
. Test hard rules for types, categories, signs, and cross-field consistency.
. Count missing values overall and by station.
. Flag unusual PM2.5 values, then inspect their time and multi-station context.
. Expose denominators in the station comparison.
. Inject known defects into a copy to verify that the audit can fail when it should.
. Record findings, actions, and remaining limitations.

For a rule stem:[r], let stem:[I_{ir}=1] when row stem:[i] violates the rule and stem:[I_{ir}=0] otherwise. The reported count is

[stem]
++++
c_r=\sum_{i=1}^{n} I_{ir}.
++++

.Mathematical insight — zero findings do not prove perfect data
[IMPORTANT]
====
[.notebook-insight-label]
*Mathematical insight.*

*Essential (P0).* An audit count of zero means that no row violated the stated rule. It does not prove that the measurements are accurate or representative. Conversely, a statistical anomaly flag means “inspect this observation”, not “delete it”. Every conclusion is conditional on the rules, data source, period, and intended use.

from pathlib import Path
import hashlib

import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
import yaml


def course_file(relative: str) -> Path:
    """Locate a course file in a repository checkout or student bundle."""
    for root in [Path.cwd(), *Path.cwd().parents]:
        candidate = root / relative
        if candidate.is_file():
            return candidate
    raise FileNotFoundError(relative)


dataset_dir = "datasets/teaching/air-quality"
manifest_path = course_file(f"{dataset_dir}/MANIFEST.yml")
manifest = yaml.safe_load(manifest_path.read_text(encoding="utf-8"))

integrity_rows = []
for declared in manifest["files"]:
    path = course_file(f"{dataset_dir}/{declared['path']}")
    observed_sha = hashlib.sha256(path.read_bytes()).hexdigest()
    observed_rows = len(pd.read_csv(path))
    integrity_rows.append(
        {
            "file": declared["path"],
            "declared rows": declared["rows"],
            "observed rows": observed_rows,
            "row count matches": observed_rows == declared["rows"],
            "byte size matches": path.stat().st_size == declared["size_bytes"],
            "checksum matches": observed_sha == declared["sha256"],
        }
    )

integrity = pd.DataFrame(integrity_rows)
assert integrity[["row count matches", "byte size matches", "checksum matches"]].all().all()
integrity

[cols="2,3,3",options="header"]

[#quality-practical-hard-audit]
[%dynamic%open,python,fail-on-error=,output=table,table-caption="Hard-rule audit of all 1,008 observations",table-description="Every row has a valid key and registered station; no exact or key duplicates, invalid wind categories, negative measurements, or dew-point-above-temperature inconsistencies are detected by the declared rules."]

key = ["station", "year", "month", "day", "hour"]
pollutants = ["PM2.5", "PM10", "SO2", "NO2", "CO", "O3"]
non_negative_weather = ["PRES", "RAIN", "WSPM"]
valid_wind = {
    "N", "NNE", "NE", "ENE", "E", "ESE", "SE", "SSE",
    "S", "SSW", "SW", "WSW", "W", "WNW", "NW", "NNW",
}


def hard_audit(frame: pd.DataFrame, station_registry: pd.DataFrame) -> dict[str, int]:
    """Count violations of declared identity, validity, and consistency rules."""
    registered = set(station_registry["station"])
    invalid_wind = frame["wd"].notna() & ~frame["wd"].isin(valid_wind)
    negative_measurement = frame[pollutants + non_negative_weather].lt(0).any(axis=1)
    return {
        "rows": len(frame),
        "missing key field rows": int(frame[key].isna().any(axis=1).sum()),
        "invalid timestamp rows": int(frame["timestamp_utc"].isna().sum()),
        "exact duplicate rows": int(frame.drop(columns="timestamp_utc").duplicated(keep=False).sum()),
        "duplicate key rows": int(frame.duplicated(key, keep=False).sum()),
        "unregistered station rows": int((~frame["station"].isin(registered)).sum()),
        "invalid wind direction rows": int(invalid_wind.sum()),
        "negative pollutant/weather rows": int(negative_measurement.sum()),
        "dew point above temperature rows": int(frame["DEWP"].gt(frame["TEMP"]).sum()),
    }


hard_findings = hard_audit(observations, stations)
hard_report = pd.DataFrame.from_dict(
    hard_findings, orient="index", columns=["affected rows"]
)
hard_report

==== 8. Flag unusual PM2.5 values within each station

For each station, compute stem:[Q_1], stem:[Q_3], and stem:[\operatorname{IQR}=Q_3-Q_1]. Flag values above stem:[Q_3+1.5\operatorname{IQR}]. This is a review rule, not an atmospheric validity limit.

[#quality-practical-anomaly-summary]
[%dynamic%open,python,fail-on-error=,output=table,table-caption="Station-specific PM2.5 review thresholds",table-description="The IQR rule flags six Aotizhongxin values, one Changping value, and two Dingling values; maxima reach 376, 443, and 410 micrograms per cubic metre respectively."]
----
pm25_groups = observations.groupby("station")["PM2.5"]
q1 = pm25_groups.transform(lambda values: values.quantile(0.25))
q3 = pm25_groups.transform(lambda values: values.quantile(0.75))
iqr = q3 - q1
observations["PM25_review_flag"] = observations["PM2.5"].gt(q3 + 1.5 * iqr)

anomaly_summary = (
    observations.groupby("station", as_index=False)
    .agg(
        Q1=("PM2.5", lambda values: values.quantile(0.25)),
        median=("PM2.5", "median"),
        Q3=("PM2.5", lambda values: values.quantile(0.75)),
        flagged=("PM25_review_flag", "sum"),
        maximum=("PM2.5", "max"),
    )
)
anomaly_summary["review_threshold"] = (
    anomaly_summary["Q3"] + 1.5 * (anomaly_summary["Q3"] - anomaly_summary["Q1"])
)
anomaly_summary.round(2)
----
