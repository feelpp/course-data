The current website is built from the `main` branch. Immutable candidate and teaching releases are published on the https://github.com/feelpp/course-data/releases[GitHub Releases page] only after the documented approval gates pass.

== Student bundle

Each approved release provides a checksum-addressed ZIP archive containing:

* generated solution-free student notebooks;
* deterministic teaching datasets and their licence/provenance records;
* dataset, result, contract, reproducibility, feedback, and AI-log templates;
* the Python and Node lockfiles plus environment instructions;
* the public schedule, rubrics, and specimen assessments;
* a machine-readable manifest of every bundled file.

The bundle contains no instructor solutions, hidden tests, live examinations, direct identifiers, or raw quarantined archive material. Verify its SHA-256 value against the release notes before use.

== Version policy

Candidate tags use `v0.9-pilot.N`. The annual teaching release uses `v1.0-2026` after corrections, academic/accessibility approval, and the representative-user pilot. A tag is evidence of an approval decision; rebuilding the same tag with different content is forbidden.

The website may show newer draft content than the latest immutable release. Assessments always name the exact bundle and checksum that govern the sitting.
