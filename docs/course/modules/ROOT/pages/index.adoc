Welcome to the CSMI course on trustworthy, reproducible, and performance-aware data processing.

The course follows the complete path from a question and a raw dataset to a defensible result:

question -> provenance -> validation -> transformation -> exploration -> modelling -> evaluation -> communication

The emphasis is not only on obtaining a numerical answer. You will learn to make the data lineage, assumptions, transformations, failure modes, and limitations reviewable by another scientist or engineer.

Start with xref:starting-with-data.adoc[why we need data processing]: what data are, how they appear, and why quality, volume and transformations affect conclusions. Continue with xref:csmi-connections.adoc[the place of the course in CSMI], then xref:data-in-action.adoc[applications and M1 internships]: Ktirio Urban Building, Sepsis, Organ on Chip with Italy, and JNL-G with LNCMI. No installation is needed for the discussion or the xref:foundations/data-lifecycle.adoc[first data audit].

== Course format

The course carries 3 ECTS and contains 28 contact hours in fourteen two-hour blocks. Each block combines a concise concept lesson, a guided demonstration, an executable lab, and an evidence-based checkpoint.

== Importance labels

Essential (P0):: Required for every student and eligible for individual assessment.
Core (P1):: Taught, practised, and assessed at least once.
Extension (P2):: Optional bridge or project material; never an unannounced prerequisite.
Deferred (P3):: Assigned to another course or kept as background reading.

After the introduction, read the xref:course-contract.adoc[course contract] and xref:course-map.adoc[course map]. Use the xref:environment.adoc[environment guide] for setup and complete the xref:readiness-check.adoc[readiness diagnostic] before Block 2.

The xref:accessibility.adoc[accessibility guide] explains keyboard, figure, and adjustment support; the xref:glossary.adoc[English--French glossary] supports technical vocabulary. Use xref:downloads.adoc[downloads and releases] for immutable student bundles and checksums, and xref:feedback.adoc[feedback] to improve future delivery without submitting personal data.

The *Foundations* route starts with data lifecycle, tables, and quality. Mathematical reference chapters support the examples at their point of use. Follow the xref:course-map.adoc[block guide] to distinguish class work, preparation, and optional reading.

The *Analytical core* develops regression, classification, regularisation, model selection, tree ensembles, PCA/clustering, and columnar performance. Its seven notebooks extend the ten foundation notebooks. Public assessment downloads also contain four specimen or project briefs; these briefs are not additional taught chapters.

Three xref:notebooks.adoc[public practice notebooks] supply synthetic inputs and response cells for assessment rehearsal. The student bundle also includes a minimal project starter with tests and CI, available from Block 5.

The *Extensions* section provides optional bridges to JAX transformations, kernels, calibration, dataframe engines, experiment tracking, drift monitoring, and downstream CSMI courses. Five extension notebooks use the declared optional routes; JAX needs the separate dependency extra. None is required for assessment.

The xref:notebooks.adoc[notebook guide] explains the execution profiles. The quick technical check covers ten foundation notebooks and four assessment briefs; it does not represent completion of all required analytical learning. Current assessment solutions and hidden tests remain outside this public site.
