Welcome to the CSMI course on trustworthy, reproducible, and performance-aware data processing.

The course follows the complete path from a question and a raw dataset to a defensible result:

question -> provenance -> validation -> transformation -> exploration -> modelling -> evaluation -> communication

The emphasis is not only on obtaining a numerical answer. You will learn to make the data lineage, assumptions, transformations, failure modes, and limitations reviewable by another scientist or engineer.

== Course format

The course carries 3 ECTS and contains 28 contact hours in fourteen two-hour blocks. Each block combines a concise concept lesson, a guided demonstration, an executable lab, and an evidence-based checkpoint.

== Importance labels

P0 Essential:: Required for every student and eligible for individual assessment.
P1 Core:: Taught, practised, and assessed at least once.
P2 Extension:: Optional bridge or project material; never an unannounced prerequisite.
P3 Deferred:: Assigned to another course or kept as background reading.

Start with the xref:course-contract.adoc[course contract], review the xref:course-map.adoc[course map], verify the xref:environment.adoc[computing environment], and complete the xref:readiness-check.adoc[readiness check].

The first complete learning path is available under *Foundations*. It includes seven executable notebooks, an integrated baseline-synthesis checkpoint, reviewed teaching tables, public acceptance checks, and delivery templates. Current assessment solutions and hidden tests remain outside this public site.

The *Analytical core* adds seven P1 notebooks covering stable/probabilistic regression, classification losses, regularisation, model selection, tree ensembles, PCA/clustering, and columnar performance. The full core CPU workflow executes all fourteen required notebooks.

The *Extensions* section provides optional bridges to JAX transformations, kernels, probability calibration, modern dataframe engines, experiment tracking, drift monitoring, and downstream CSMI courses. Its one additional notebook uses a separate dependency extra and is never required for assessment.
