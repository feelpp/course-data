== From features to similarities

.Definition: Positive-semidefinite kernel
[.def#def:psd-kernel]
****
A symmetric function stem:[k:\mathcal X\times\mathcal X\to\mathbb R] is positive semidefinite when, for every finite sample stem:[x_1,\ldots,x_n] and every stem:[a\in\mathbb R^n],

[stem]
++++
a^\top K a\ge 0,
\qquad K_{ij}=k(x_i,x_j).
++++

The matrix stem:[K] is the Gram matrix. Positive semidefiniteness makes it behave like an inner-product matrix, possibly in a feature space that is never constructed explicitly.
****

For the radial-basis-function kernel,

[stem]
++++
k_\gamma(x,z)=\exp\!\left(-\gamma\lVert x-z\rVert_2^2\right),
++++

large stem:[\gamma] makes similarity very local, while small stem:[\gamma] makes many observations look alike. Scaling therefore changes the model, not merely the presentation of the inputs.

== Kernel Ridge and its spectral filter

Kernel Ridge solves

[stem]
++++
(K+\alpha I)c=y,
\qquad
\widehat f(x)=\sum_{i=1}^{n}c_i k(x_i,x),
++++

with stem:[\alpha>0]. Solve the linear system; never form stem:[(K+\alpha I)^{-1}] explicitly.

If stem:[K=Q\Lambda Q^\top] with eigenvalues stem:[\lambda_j\ge0], then

[stem]
++++
c
=Q(\Lambda+\alpha I)^{-1}Q^\top y
=\sum_j\frac{q_j^\top y}{\lambda_j+\alpha}q_j.
++++

Regularisation limits amplification in weak spectral directions. For a response perturbation stem:[\delta y],

[stem]
++++
\lVert\delta c\rVert_2
\le
\frac{\lVert\delta y\rVert_2}{\lambda_{\min}(K)+\alpha}
\le
\frac{\lVert\delta y\rVert_2}{\alpha}.
++++

This is a stability bound on coefficients for a fixed Gram matrix. It is not a generalisation guarantee and does not account for uncertainty in the observations or kernel choice.

== Error estimation

The validation split must contain the complete selection of stem:[\alpha], stem:[\gamma], preprocessing, and kernel family. Fold scores estimate performance of that selection procedure on populations represented by the resampling design; they do not justify an independent-and-identically-distributed claim when groups or time dependence are ignored.

For fold losses stem:[L_1,\ldots,L_K], a descriptive standard error is

[stem]
++++
\widehat{\operatorname{se}}(\bar L)
=
\frac{s_L}{\sqrt K}.
++++

Because validation folds overlap in their training data, this is not generally an exact inferential standard error. Preserve an untouched final set, report fold dispersion, and inspect residual structure.

== Worked example: nonlinear oracle with a linear baseline

[.worked-example-context#worked-kernel-context]
=== Context

*Importance:* Extension (P2)

A small sensor response has a smooth nonlinear component. We compare a standardised linear Ridge baseline with an RBF Kernel Ridge model. The held-out test set is used once, after a five-fold search on the training set.

[.worked-example-method#worked-kernel-method]
=== Method

*Importance:* Extension (P2)

Generate stem:[y=0.6x+\sin(2.2x)+\varepsilon], with stem:[\varepsilon\sim\mathcal N(0,0.18^2)]. Fit both models through pipelines so scaling is learned inside each validation fold. Search a small joint grid for stem:[\alpha] and stem:[\gamma], then compare test root mean squared error.

.Mathematical insight — regularisation bounds spectral amplification
[IMPORTANT]
====
[.notebook-insight-label]
*Mathematical insight.*

*Extension (P2).* The eigen-direction stem:[q_j] is multiplied by stem:[1/(\lambda_j+\alpha)]. Adding stem:[\alpha] therefore places a finite upper bound stem:[1/\alpha] on response-noise amplification in the coefficient vector. This explains a numerical benefit of regularisation, but neither chooses the scientifically appropriate kernel nor proves predictive validity.
====

[.worked-example-implementation#worked-kernel-implementation]
=== Implementation

*Importance:* Extension (P2)

The table reports the untouched test error and the regularised Gram-matrix condition number. The figure shows both fitted response curves; the test metric, not visual smoothness, supplies the comparison.

[#kernel-methods-table]
[%dynamic%open,python,fail-on-error=,output=table,table-caption="Linear and RBF Kernel Ridge diagnostics",table-description="Rows compare the selected regularisation, RBF scale where applicable, untouched test RMSE, and the regularised Gram-matrix condition number."]
----
import numpy as np
import pandas as pd
from sklearn.kernel_ridge import KernelRidge
from sklearn.linear_model import Ridge
from sklearn.metrics import root_mean_squared_error
from sklearn.metrics.pairwise import rbf_kernel
from sklearn.model_selection import GridSearchCV, KFold, train_test_split
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler

rng = np.random.default_rng(20260724)
x = rng.uniform(-3.0, 3.0, size=180)
y = 0.6 * x + np.sin(2.2 * x) + rng.normal(0.0, 0.18, size=x.size)
X = x.reshape(-1, 1)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.30, random_state=20260724
)

folds = KFold(n_splits=5, shuffle=True, random_state=20260724)
linear_search = GridSearchCV(
    Pipeline([("scale", StandardScaler()), ("model", Ridge())]),
    {"model__alpha": [0.01, 0.1, 1.0, 10.0]},
    scoring="neg_root_mean_squared_error",
    cv=folds,
)
kernel_search = GridSearchCV(
    Pipeline([("scale", StandardScaler()), ("model", KernelRidge(kernel="rbf"))]),
    {
        "model__alpha": [0.001, 0.01, 0.1, 1.0],
        "model__gamma": [0.1, 0.3, 1.0, 3.0],
    },
    scoring="neg_root_mean_squared_error",
    cv=folds,
)
linear_search.fit(X_train, y_train)
kernel_search.fit(X_train, y_train)

linear_rmse = root_mean_squared_error(y_test, linear_search.predict(X_test))
kernel_rmse = root_mean_squared_error(y_test, kernel_search.predict(X_test))
best_alpha = kernel_search.best_params_["model__alpha"]
best_gamma = kernel_search.best_params_["model__gamma"]
scaled_train = kernel_search.best_estimator_.named_steps["scale"].transform(X_train)
gram = rbf_kernel(scaled_train, gamma=best_gamma)
eigenvalues = np.linalg.eigvalsh(gram)
regularised_condition = (eigenvalues[-1] + best_alpha) / (eigenvalues[0] + best_alpha)

assert kernel_rmse < linear_rmse
assert np.isfinite(regularised_condition)

kernel_diagnostics = pd.DataFrame(
    {
        "alpha": [
            linear_search.best_params_["model__alpha"],
            best_alpha,
        ],
        "gamma": ["not applicable", best_gamma],
        "test RMSE": [linear_rmse, kernel_rmse],
        "regularised Gram condition": ["not applicable", regularised_condition],
    },
    index=["linear Ridge", "RBF Kernel Ridge"],
)
kernel_diagnostics
----

=== Conclusion

*Importance:* Extension (P2)

Kernel Ridge is justified here by a nonlinear signal, leakage-safe selection, a simpler baseline, and final test evidence. Residual risk remains from finite sampling, grid choice, and the match between the RBF similarity assumption and the real measurement process. For large stem:[n], the stem:[n^2] storage and near-stem:[n^3] direct solve motivate approximations or another model family.

== Scaling boundary

A dense Gram matrix stores stem:[n^2] values. With 64-bit floats its payload alone is approximately

[stem]
++++
8n^2\ \text{bytes},
++++

before workspace and cross-validation copies. A direct dense solve can approach stem:[O(n^3)] work, and prediction against all training observations costs stem:[O(n)] kernel evaluations per new case.
