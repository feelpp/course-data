The P0/P1 path makes data, validation, evaluation, and results trustworthy; downstream courses deepen software engineering, numerical models, accelerators, databases, and distributed execution. See the https://csmi.cemosis.fr/en/csmi/csmi-2024-2028/index.html#_courses[CSMI 2024–2028 course map] for the programme context.

== Deferred archive map

The legacy PyTree, manual/Optax training, hyperparameter-agent, sentiment, MNIST, two-dimensional neural-network, and deep-architecture notebooks are retained only in the restricted source archive. They are not published as optional Data Processing units. The detailed ownership proposal is recorded in the repository governance documentation.

Kernel methods, calibration, local engines, tracking, and drift on this site are compact bridges. They are not hidden prerequisites and are not eligible for controls or the final examination.
