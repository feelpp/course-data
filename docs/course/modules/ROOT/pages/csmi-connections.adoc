CSMI connects mathematical models, computation and observations. This course develops the data preparation and evaluation needed to make those connections work in practice.

== Where these skills lead

Later, *Signal and Image Processing* develops ways to extract information from signals and images; *Optimization* supplies methods for fitting models; *Scientific Machine Learning* combines learning with scientific questions. Numerical methods, reduced models and uncertainty courses deepen model–data comparisons. Projects and internships bring these skills together.

This is our teaching map, using the course names and sequence in the https://csmi.cemosis.fr/fr/csmi/csmi-2024-2028/index.html#_courses[CSMI 2024–2028 programme description]. Several S1 courses run alongside this one: you are not expected to have completed them already. We introduce the concepts we need as we use them.
