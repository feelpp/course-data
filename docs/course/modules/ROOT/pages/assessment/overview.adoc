Assessment follows the complete evidence chain from question and data to reproducible conclusion. Predictive score alone can never earn most of the marks.

== Components

[cols="3,1,2,5",options="header"]
|===
|Component |Weight |Default AI mode |Direct evidence
|Control 1 |20% |A |Individual data audit, validated join, quality checks, split, safe baseline, metric and limitations.
|Mini-project |25% |B |Pair repository and report plus individual code/oral verification.
|Control 2 |15% |A |Individual audit and repair of a deliberately flawed analysis.
|Final exam |40% |A |Integrated data, method, implementation, evaluation, and governance competence.
|===

Mode A prohibits external generative AI. Mode B permits it with disclosure and independent verification. The assessment header is authoritative if a different mode is announced. Examination, hidden-test, confidential, personal, or embargoed material must never be uploaded to an external service.

Control 1 assesses Essential (P0) data handling, uncertainty/metric interpretation, and safe baseline practice from Blocks 1–7; it does not require independent Core (P1) modelling. The two timed controls occupy 70 minutes in Block 8 and 55 minutes in Block 14. The 165-minute final examination is a separate assessment session.

Individual project verification is scheduled separately from Block 14. The course lead announces appointments and staffing before project submission.

== Critical validity rule

A serious Essential (P0) failure caps the affected criterion even if a final metric is high. Examples include a many-to-many join that changes the unit of analysis, fitting preprocessing on test data, target leakage, untraceable or impermissible data, fabricated evidence, or a workflow that cannot be rerun. The cap is local to the affected criterion unless academic-integrity rules require a wider decision.

== Required implementation depth

Students implement an Essential baseline and one approved Core method route in the mini-project. In the ensemble and clustering sessions, they run and interpret the supplied comparisons, change one controlled condition, and explain assumptions and failure cases. They are not required to implement every algorithm from scratch. The final examination selects one announced Core family; students prepare interpretation across the stated families and implement the method specified by their paper.
