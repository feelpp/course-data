Student notebooks are generated from reviewed instructor sources. The generator removes solutions and instructor-only cells, clears outputs and execution counts, validates metadata, and writes deterministic notebook files.

== Working rule

. Download or regenerate the student notebook.
. Complete the marked tasks without changing the data contract.
. Restart the kernel and run all cells.
. Check that results are deterministic and that paths are repository-relative.
. Record any AI assistance according to the assessment mode.

Never submit a notebook whose correctness depends on cells being run in a hidden order.
