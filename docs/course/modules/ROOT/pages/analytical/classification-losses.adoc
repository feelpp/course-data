Logistic and softmax regression model class scores/logits and convert them to probabilities through a normalised exponential family. Cross-entropy is the categorical negative log-likelihood; it is not a synonym for classification error.

== Stable computation

Direct `exp(logit)` overflows for large logits. Subtract the row maximum before exponentiating, or use `logsumexp`/a maintained library loss. Softmax is invariant to adding the same constant to every class logit. Binary logistic loss should use a stable `logaddexp` formulation.

The loss trains probability scores; a threshold or argmax creates a decision. Calibration, prevalence, and asymmetric costs determine whether the default decision rule is suitable.

Demonstrate overflow in the naive expression, verify shift invariance, and compare the result with scikit-learn/SciPy. == Independent transfer

Create an imbalanced three-class synthetic problem. Compare accuracy, macro-F1, per-class recall, and log loss. Explain one case where log loss improves while the argmax confusion matrix is unchanged, and one case where a class-weight change improves minority recall but worsens probability interpretation.

== Assessment evidence

Required evidence includes the likelihood/loss link, stable formula, shape/label encoding, oracle test, class-conditional interpretation, and separation of score, probability, and decision. Framework-specific neural-network mechanics are not required.
