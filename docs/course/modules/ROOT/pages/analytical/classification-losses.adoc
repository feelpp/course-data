Logistic and softmax regression model class scores/logits and convert them to probabilities through a normalised exponential family. Cross-entropy is the categorical negative log-likelihood; it is not a synonym for classification error.

== Binary logistic model

For stem:[x_i\in\mathbb R^p], define the logit stem:[\eta_i=x_i^\top\beta] and probability

[stem]
++++
p_i=P(Y_i=1\mid X_i=x_i)=\sigma(\eta_i)
=\frac{1}{1+e^{-\eta_i}}.
++++

.Definition: Binary cross-entropy
[.def#def:binary-cross-entropy]
****
For stem:[y_i\in\{0,1\}], the average negative Bernoulli log-likelihood is

[stem]
++++
\widehat L(\beta)
=-\frac1n\sum_{i=1}^{n}
\left[y_i\log p_i+(1-y_i)\log(1-p_i)\right].
++++
****

Using stem:[\operatorname{softplus}(t)=\log(1+e^t)], one stable per-observation form is

[stem]
++++
\ell(y,\eta)=\operatorname{softplus}(\eta)-y\eta.
++++

Its gradient is stem:[\nabla_\beta\widehat L=X^\top(p-y)/n]. The residual-like term stem:[p_i-y_i] is probability error, not a class label error.

== Multiclass softmax

For stem:[K] classes and logits stem:[z_i\in\mathbb R^K],

[stem]
++++
p_{ik}=\frac{e^{z_{ik}}}{\sum_{j=1}^{K}e^{z_{ij}}},
\qquad
\ell_i=-\log p_{i,y_i}
=-z_{i,y_i}+\log\sum_{j=1}^{K}e^{z_{ij}}.
++++

.Proposition: Shift invariance
[.prop#prop:softmax-shift]
****
For any scalar stem:[c], stem:[\operatorname{softmax}(z+c\mathbf 1)=\operatorname{softmax}(z)]. Multiplying numerator and denominator by stem:[e^{-c}] cancels the shift. Choosing stem:[c=-\max_j z_j] prevents overflow while preserving probabilities.
****

== Stable computation

Direct `exp(logit)` overflows for large logits. Subtract the row maximum before exponentiating, or use `logsumexp`/a maintained library loss. Softmax is invariant to adding the same constant to every class logit. Binary logistic loss should use a stable `logaddexp` formulation.

The loss trains probability scores; a threshold or argmax creates a decision. Calibration, prevalence, and asymmetric costs determine whether the default decision rule is suitable.

== Error estimation

On an untouched test set of size stem:[m], log loss is an empirical mean stem:[\widehat L=m^{-1}\sum_i\ell_i]. If test units are independent, its standard error is stem:[s_\ell/\sqrt m]. Because log loss is unbounded when the model assigns a near-zero probability to the observed class, inspect the loss distribution and influential cases rather than reporting only a symmetric interval.

For recall stem:[r=TP/(TP+FN)] with stem:[m_+=TP+FN] independent positive cases, a rough binomial estimate is

[stem]
++++
\widehat{\operatorname{SE}}(r)
=\sqrt{\frac{r(1-r)}{m_+}}.
++++

Use a group or block bootstrap when cases share machines, patients, sites, or time dependence. Threshold selection and probability calibration must occur before final evaluation; otherwise the uncertainty estimate omits selection optimism.

=== Method

*Importance:* Core (P1)

.Example: Same decision, different log loss
[.examp#ex:log-loss-confidence]
****
For a positive case, probabilities stem:[0.6] and stem:[0.9] both predict class 1 at threshold stem:[0.5], but their losses are

[stem]
++++
-\log(0.6)\approx0.511,
\qquad
-\log(0.9)\approx0.105.
++++

The confusion matrix is unchanged while log loss rewards the better probability assignment. If the true class were 0, the losses would instead be stem:[-\log(0.4)\approx0.916] and stem:[-\log(0.1)\approx2.303]; overconfidence is penalised strongly.
****

.Mathematical insight — proper loss evaluates the probability, not only the class
[IMPORTANT]
====
[.notebook-insight-label]
*Mathematical insight.*

*Core (P1).* Log loss is a strictly proper scoring rule: in expectation it is minimised by reporting the true conditional probability. Threshold accuracy discards the distance from the decision boundary, whereas stem:[-\log p_y] rewards honest probability information and strongly penalises confident errors. Stable `logsumexp` computation preserves this mathematical objective without overflowing.
====

from pathlib import Path

import numpy as np
import pandas as pd
from scipy.special import logsumexp
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import log_loss
from sklearn.model_selection import train_test_split
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler


def stable_softmax(logits: np.ndarray) -> np.ndarray:
    """Normalise row logits after subtracting their maximum."""
    shifted = logits - logits.max(axis=1, keepdims=True)
    exponentials = np.exp(shifted)
    return exponentials / exponentials.sum(axis=1, keepdims=True)


def cross_entropy(logits: np.ndarray, labels: np.ndarray) -> float:
    """Compute mean categorical negative log-likelihood without log(softmax)."""
    log_normaliser = logsumexp(logits, axis=1)
    selected_logits = logits[np.arange(len(labels)), labels]
    return float(np.mean(log_normaliser - selected_logits))


# These logits overflow in a naive exp(logit) implementation.
toy_logits = np.array([[1000.0, 1001.0, 999.0], [-1000.0, -1001.0, -999.0]])
toy_labels = np.array([1, 2])
toy_probability = stable_softmax(toy_logits)
toy_loss = cross_entropy(toy_logits, toy_labels)
normalisation_error = float(np.max(np.abs(toy_probability.sum(axis=1) - 1.0)))
shift_error = float(
    np.max(np.abs(toy_probability - stable_softmax(toy_logits + 12345.0)))
)
assert np.isfinite(toy_probability).all() and np.isfinite(toy_loss)
assert normalisation_error < 1.0e-14
assert shift_error < 1.0e-12

# Locate the canonical file both in a repository checkout and in a student bundle.
def course_file(relative: str) -> Path:
    for root in [Path.cwd(), *Path.cwd().parents]:
        candidate = root / relative
        if candidate.is_file():
            return candidate
    raise FileNotFoundError(relative)


# Test the same loss family on a stratified, bounded Dry Bean subset.
data_path = course_file("datasets/teaching/dry-bean/observations.csv")
beans = pd.read_csv(data_path).groupby("Class", group_keys=False).sample(
    n=180, random_state=20260722
)
X_train, X_test, y_train, y_test = train_test_split(
    beans.drop(columns="Class"),
    beans["Class"],
    test_size=0.25,
    random_state=20260722,
    stratify=beans["Class"],
)
model = make_pipeline(
    StandardScaler(), LogisticRegression(max_iter=1500, random_state=20260722)
).fit(X_train, y_train)
bean_log_loss = float(log_loss(y_test, model.predict_proba(X_test), labels=model.classes_))
assert bean_log_loss < 0.8

pd.DataFrame(
    {
        "value": [normalisation_error, shift_error, toy_loss, bean_log_loss],
        "required interpretation": [
            "probabilities sum to one",
            "common logit shifts do not change probabilities",
            "extreme logits remain finite",
            "protected-sample probabilistic error",
        ],
    },
    index=[
        "maximum row-sum error",
        "maximum shift-invariance error",
        "toy cross-entropy",
        "Dry Bean log loss",
    ],
)

import matplotlib.pyplot as plt

# logaddexp(0, eta) is a stable implementation of softplus(eta).
eta = np.linspace(-12.0, 12.0, 400)
loss_y0 = np.logaddexp(0.0, eta)
loss_y1 = np.logaddexp(0.0, eta) - eta
plt.style.use("tableau-colorblind10")
fig, ax = plt.subplots(figsize=(7.5, 4.2), constrained_layout=True)
ax.plot(eta, loss_y0, linestyle="--", label="target y=0")
ax.plot(eta, loss_y1, linestyle="-", label="target y=1")
ax.axvline(0.0, color="black", linewidth=1, alpha=0.6)

=== Conclusion

*Importance:* Essential (P0)

The stem:[0.9] prediction is the better probability assignment for the positive case even though both predictions make the same class decision. Softmax normalisation, shift invariance, and cross-entropy agreement are implementation checks; protected-test log loss is sampling evidence for one deterministic split.
