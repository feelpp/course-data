A decision tree recursively partitions feature space to reduce impurity or prediction loss. Depth, leaf size, and pruning control variance. Small data changes can produce a different tree, so a diagram is not a stable explanation by itself.

Bagging averages decorrelated trees; random forests add feature subsampling and provide out-of-bag evidence. Boosting fits learners sequentially to correct current errors and requires learning-rate/tree-complexity regularisation. All must be compared with the same protected baseline and metric.

== Guided laboratory

On AI4I pre-outcome features, compare a depth-controlled tree, random forest with OOB score, and histogram gradient boosting against the logistic/dummy baselines. Use fixed budgets, inspect class-conditional errors, and compare impurity importance with held-out permutation importance.

== Independent transfer

Perturb the training sample seed and report tree structure/importance instability. Compare forest OOB and protected-test evidence. Select one false-negative subgroup and propose a data or threshold investigation. Explain why predictive importance is not a causal intervention effect and why correlated features divide importance.

== Assessment evidence

Students must explain split/impurity, complexity control, bagging variance reduction, forest feature subsampling/OOB, and boosting’s sequential correction. Marks require baseline comparison, protected evaluation, failure analysis, and interpretation caveats—not a leaderboard.
