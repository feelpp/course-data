PCA finds orthogonal directions of maximum centred variance through SVD. Components depend on scale, sample, and measurement process; explained variance is not automatically scientific importance.

K-means minimises within-cluster squared Euclidean distance and favours roughly spherical, similarly scaled groups. Hierarchical linkage encodes another geometry; DBSCAN identifies density-connected regions and noise but depends strongly on scale and neighbourhood parameters.

== Guided laboratory

Standardise Dry Bean shape features without using `Class`, fit PCA, inspect reconstruction/explained variance, and compare k-means, agglomerative clustering, and DBSCAN on a controlled subset. Challenge k-means across seeds and bootstrap samples; use silhouette only as one internal diagnostic. Reveal class labels only for post-hoc interpretation.

== Independent transfer

Create spherical, anisotropic, varying-density, and noisy oracle datasets. Predict which algorithm should fail, test the prediction, and compare stability under resampling. Then cluster air-quality station/day profiles and obtain domain evidence before naming a cluster.

== Assessment evidence

Students must state scaling/centring, objective and geometry, distinguish transformation fitting from visualisation, quantify stability, challenge internal scores, and avoid calling clusters true classes. Class/target labels cannot enter fitting.
