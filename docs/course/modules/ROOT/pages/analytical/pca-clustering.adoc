[.course-badge.priority-p1]#P1 Core# [.course-badge.difficulty-d3]#D3 Synthesis#

PCA finds orthogonal directions of maximum centred variance through SVD. Components depend on scale, sample, and measurement process; explained variance is not automatically scientific importance.

K-means minimises within-cluster squared Euclidean distance and favours roughly spherical, similarly scaled groups. Hierarchical linkage encodes another geometry; DBSCAN identifies density-connected regions and noise but depends strongly on scale and neighbourhood parameters.

== Principal component analysis

Let stem:[X\in\mathbb R^{n\times p}] be column-centred. Its singular-value decomposition is

[stem]
++++
X=U\Sigma V^\top,
\qquad
\Sigma=\operatorname{diag}(\sigma_1,\ldots,\sigma_r),
\quad \sigma_1\ge\cdots\ge\sigma_r>0.
++++

.Definition: Principal directions and scores
[.def#def:pca]
****
The columns stem:[v_j] of stem:[V] are principal directions. The score of observation stem:[i] on component stem:[j] is stem:[z_{ij}=x_i^\top v_j]. The sample variance explained by component stem:[j] is

[stem]
++++
\lambda_j=\frac{\sigma_j^2}{n-1},
\qquad
\operatorname{EVR}_j=\frac{\lambda_j}{\sum_{\ell=1}^{r}\lambda_\ell}.
++++
****

.Theorem: Best rank-q reconstruction
[.thm#thm:eckart-young]
****
The truncated SVD stem:[X_q=U_q\Sigma_qV_q^\top] minimises stem:[\lVert X-A\rVert_F] over matrices stem:[A] of rank at most stem:[q], and

[stem]
++++
\lVert X-X_q\rVert_F^2=\sum_{j=q+1}^{r}\sigma_j^2.
++++

This is an approximation result in squared Euclidean geometry, not a guarantee that the retained components preserve a scientific target.
****

Standardisation replaces the covariance geometry by correlation-like geometry. It is appropriate when differing units should not determine variance dominance, but it also gives a noisy low-variance measurement the same marginal scale as a precise one.

== Clustering objectives

.Definition: K-means objective
[.def#def:kmeans]
****
For assignments stem:[c_i\in\{1,\ldots,K\}] and centroids stem:[\mu_1,\ldots,\mu_K], K-means minimises

[stem]
++++
J(c,\mu)=\sum_{i=1}^{n}\lVert x_i-\mu_{c_i}\rVert_2^2.
++++

Alternating assignment and centroid updates decrease stem:[J] but can converge to different local minima.
****

DBSCAN instead defines a neighbourhood stem:[N_\varepsilon(x)=\{x_i:\lVert x_i-x\rVert\le\varepsilon\}] and connects points whose neighbourhood contains at least `min_samples` observations. It can represent non-convex clusters but struggles when densities vary strongly.

== Error estimation and stability

PCA directions and cluster assignments are sample-dependent estimators. Refit across bootstrap samples or meaningful groups. Align PCA signs/directions before comparison; compare subspaces when eigenvalues are close because individual directions may rotate without changing the spanned space.

For clustering, record objective variation, assignment agreement, and sensitivity to scaling, seed, stem:[K], distance, and algorithm. A stability score can compare pairs of co-clustered observations across fits, but high stability can still describe a stable artefact of sampling or preprocessing.

Internal scores such as silhouette use the same geometry that defined the clusters. They do not prove external usefulness. If labels are revealed post hoc, keep them entirely outside fitting and state that agreement is evaluation, not discovery.

[.worked-example-method#worked-pca-method]
=== Method

*Importance:* Core (P1)

.Example: Diagonal covariance
[.examp#ex:pca-diagonal]
****
Suppose a centred two-feature sample has covariance

[stem]
++++
S=\begin{bmatrix}9&0\\0&1\end{bmatrix}.
++++

The principal directions are the coordinate axes, with explained-variance ratios stem:[9/10] and stem:[1/10]. Retaining one component minimises squared reconstruction error, but if the second feature is a precisely measured safety variable, discarding it may still be scientifically unacceptable.
****

.Mathematical insight — PCA optimises reconstruction, not relevance
[IMPORTANT]
====
[.notebook-insight-label]
*Mathematical insight.*

*Core (P1).* The leading stem:[k] eigenvectors solve the rank-stem:[k] least-squares reconstruction problem, and the discarded variance is the sum of omitted eigenvalues. This theorem concerns Euclidean reconstruction of the scaled features. It does not preserve low-variance targets, causal variables, rare regimes, or cluster identity; preprocessing and the scientific loss determine whether variance is an appropriate proxy for information.
====

[.worked-example-implementation#worked-pca-implementation]
=== Implementation

*Importance:* Essential (P0)

The diagonal covariance example makes the eigenvalues, principal directions, and stem:[90\%] explained-variance ratio checkable by hand. The executable extension is an explicitly class-balanced benchmark: `Class` is used to sample 160 rows per class, and K=7 is prescribed from the benchmark design. Class labels are then excluded from scaling, PCA, and clustering. This is not a label-blind discovery experiment. Its table reports retained dimension, cumulative explained variance, silhouette, stability across seeds, and a post-hoc comparison with the known benchmark labels. The score plot visualises the fitted geometry but is not used as proof of natural classes.

[%dynamic%open,python,fail-on-error=,output=table,table-caption="PCA and K-means validation diagnostics",table-description="Rows report retained PCA dimension, cumulative explained variance, K-means silhouette, agreement across two fixed seeds, and post-hoc agreement with known Dry Bean benchmark labels."]

from pathlib import Path

import pandas as pd
from sklearn.cluster import KMeans
from sklearn.decomposition import PCA
from sklearn.metrics import adjusted_rand_score, silhouette_score
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler

def course_file(relative: str) -> Path:
    """Locate canonical data in a repository checkout or student bundle."""
    for root in [Path.cwd(), *Path.cwd().parents]:
        candidate = root / relative
        if candidate.is_file():
            return candidate
    raise FileNotFoundError(relative)


data_path = course_file("datasets/teaching/dry-bean/observations.csv")
beans = pd.read_csv(data_path).groupby("Class", group_keys=False).sample(
    n=160, random_state=20260722
)
X = beans.drop(columns="Class")
class_labels = beans["Class"]

# Sampling used Class and K=7 is prescribed; labels are not passed to the estimators.
transform = make_pipeline(StandardScaler(), PCA(n_components=0.90, random_state=20260722))
reduced = transform.fit_transform(X)
clusters_a = KMeans(7, n_init=20, random_state=20260722).fit_predict(reduced)
clusters_b = KMeans(7, n_init=20, random_state=20260723).fit_predict(reduced)
pca = transform.named_steps["pca"]
cumulative_variance = float(pca.explained_variance_ratio_.sum())
silhouette = float(silhouette_score(reduced, clusters_a))
seed_stability = float(adjusted_rand_score(clusters_a, clusters_b))
posthoc_class_ari = float(adjusted_rand_score(class_labels, clusters_a))
assert cumulative_variance >= 0.90
assert reduced.shape[1] < X.shape[1]
assert seed_stability > 0.80

pd.DataFrame(
    {
        "value": [
            reduced.shape[1],
            cumulative_variance,
            silhouette,
            seed_stability,
            posthoc_class_ari,
        ],
        "status": [
            "selected by 90% variance rule",
            "internal transformation diagnostic",
            "internal geometry diagnostic",
            "algorithmic stability diagnostic",
            "post-hoc external comparison only",
        ],
    },
    index=[
        "retained components",
        "cumulative explained variance",
        "silhouette",
        "ARI across seeds",
        "ARI with benchmark class",
    ],
)

[%dynamic%open,python,fail-on-error=,output=table,table-caption="Clustering methods under two controlled geometries",table-description="K-means, single-link hierarchical clustering, and DBSCAN report cluster count, noise fraction, oracle ARI, and silhouette on assigned points for blobs and two moons."]

from sklearn.cluster import AgglomerativeClustering, DBSCAN
from sklearn.datasets import make_blobs, make_moons

geometries = {
    "blobs": make_blobs(n_samples=240, centers=[[-1, -1], [1, 1]], cluster_std=0.22, random_state=20260905),
    "moons": make_moons(n_samples=240, noise=0.04, random_state=20260905),
}
geometry_labels = {}
geometry_rows = []
for dataset, (coordinates, oracle_labels) in geometries.items():
    algorithms = {
        "K-means": KMeans(2, n_init=10, random_state=20260905),
        "single-link": AgglomerativeClustering(n_clusters=2, linkage="single"),
        "DBSCAN": DBSCAN(eps=0.23, min_samples=5),
    }
    for name, algorithm in algorithms.items():
        assignment = algorithm.fit_predict(coordinates)
        geometry_labels[(dataset, name)] = assignment
        assigned = assignment != -1
        number = len(set(assignment[assigned]))
        silhouette_assigned = (silhouette_score(coordinates[assigned], assignment[assigned])
                               if 1 < number < int(assigned.sum()) else np.nan)
        geometry_rows.append([dataset, name, number, float((~assigned).mean()),
                              adjusted_rand_score(oracle_labels, assignment), silhouette_assigned])
geometry_evidence = pd.DataFrame(geometry_rows, columns=["geometry", "method", "clusters", "noise fraction", "oracle ARI", "silhouette of assigned points"])
geometry_evidence

[.worked-example-conclusion#worked-pca-conclusion]
=== Conclusion

*Importance:* Essential (P0)

The fitted transformation provides a compact and algorithmically stable representation for this controlled dataset, but it does not establish seven natural scientific classes. Explained variance measures reconstruction of the standardised feature space, silhouette measures internal separation under a chosen distance, and adjusted Rand index measures agreement between partitions. They are not interchangeable validation measures. The two-dimensional plot omits later components, and stability across two seeds is only a minimal algorithmic check; scientific cluster meaning requires external evidence.
