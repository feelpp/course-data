Linear regression is both a predictive baseline and a bridge between linear algebra, numerical analysis, and probability. The algebraic normal equations do not justify explicitly computing `(X^T X)^{-1}` in production code.

== Mathematical and numerical contract

For `y = Xβ + ε`, ordinary least squares minimises `||Xβ-y||²`. Under independent Gaussian errors with constant variance, the same coefficient estimate maximises the likelihood. These are distinct statements: the numerical objective can be used without believing every probabilistic assumption, while confidence or likelihood interpretations require the assumptions.

`X^T X` squares the condition number. Use `lstsq`, QR, or SVD; inspect singular values and scaling; use Ridge when shrinkage is substantively and computationally justified. Residual plots must challenge linearity, variance, dependence, and subgroup/time structure.

== Guided laboratory

Construct a nearly collinear synthetic design with known coefficients. Compare explicit normal-equation inversion, `numpy.linalg.lstsq`, and Ridge across perturbations. Connect the squared-error objective to Gaussian negative log-likelihood and report MAE, RMSE, condition number, and coefficient instability.

== Independent transfer

Use the air-quality teaching table to predict PM2.5 from weather variables for one declared station/time scope. Create a protected chronological holdout, fit a stable linear baseline, inspect residuals by time and predicted value, and state which Gaussian/independence assumptions are not credible. Compare prediction stability after standardising or removing one collinear feature.

== Assessment evidence

Students must explain the objective/likelihood connection, reject explicit inversion, interpret conditioning and residuals, and distinguish predictive evidence from parameter or causal claims. Equivalent stable solvers receive full credit when justified.
