Linear regression is both a predictive baseline and a bridge between linear algebra, numerical analysis, and probability. The algebraic normal equations do not justify explicitly computing stem:[(X^\top X)^{-1}] in production code.

== Mathematical setting

Let stem:[X\in\mathbb R^{n\times p}] be the design matrix, stem:[y\in\mathbb R^n] the response, and stem:[\beta\in\mathbb R^p] the coefficient vector.

.Definition: Ordinary least-squares estimator
[.def#def:ols]
****
The ordinary least-squares estimator minimises the empirical squared loss

[stem]
++++
\widehat\beta
=\operatorname*{argmin}_{\beta\in\mathbb R^p}
\frac{1}{n}\lVert y-X\beta\rVert_2^2.
++++
****

Differentiating gives

[stem]
++++
\nabla_\beta\lVert y-X\beta\rVert_2^2
=2X^\top(X\beta-y).
++++

At a minimiser, stem:[X^\top X\widehat\beta=X^\top y]. These *normal equations* characterise the solution; they do not prescribe an explicit matrix inverse. If stem:[X] has deficient column rank, several coefficient vectors can produce the same fitted values.

== Probability connection

Assume temporarily that

[stem]
++++
Y_i=x_i^\top\beta+\varepsilon_i,
\qquad
\varepsilon_i\overset{\mathrm{iid}}{\sim}\mathcal N(0,\sigma^2).
++++

The negative log-likelihood, up to an additive constant, is

[stem]
++++
-\log p(y\mid X,\beta,\sigma^2)
=\frac n2\log\sigma^2
+\frac{1}{2\sigma^2}\lVert y-X\beta\rVert_2^2.
++++

For fixed stem:[\sigma^2], maximum likelihood and least squares have the same stem:[\widehat\beta]. The Gaussian, independence, linear-mean, and constant-variance assumptions are needed for the likelihood and classical uncertainty statements—not for computing a squared-error baseline.

== Numerical contract

For stem:[y=X\beta+\varepsilon], ordinary least squares minimises stem:[\lVert X\beta-y\rVert_2^2]. Under independent Gaussian errors with constant variance, the same coefficient estimate maximises the likelihood. These are distinct statements: the numerical objective can be used without believing every probabilistic assumption, while confidence or likelihood interpretations require the assumptions.

The normal-equation matrix stem:[X^\top X] squares the condition number. Use `lstsq`, QR, or SVD; inspect singular values and scaling; use Ridge when shrinkage is substantively and computationally justified. Residual plots must challenge linearity, variance, dependence, and subgroup/time structure.

With the singular-value decomposition stem:[X=U\Sigma V^\top], the least-squares solution uses stem:[\Sigma^+] rather than dividing blindly by near-zero singular values:

[stem]
++++
\widehat\beta=V\Sigma^+U^\top y.
++++

Small singular values identify directions in coefficient space that are weakly determined by the data. Predictions can remain stable while individual coefficients vary greatly.

== Error estimation

Under the Gaussian linear model with full column rank,

[stem]
++++
\widehat\sigma^2
=\frac{\lVert y-X\widehat\beta\rVert_2^2}{n-p},
\qquad
\operatorname{Cov}(\widehat\beta\mid X)
=\sigma^2(X^\top X)^{-1}.
++++

These formulas quantify sampling variation conditional on stem:[X]. They do not include model misspecification, measurement error in stem:[X], data-dependent feature selection, temporal dependence, or distribution shift. When those assumptions fail, use group/time-aware resampling and report residual structure rather than presenting classical standard errors as universal.

For protected test losses stem:[\ell_i=(y_i-\widehat y_i)^2], estimate mean-squared prediction risk and its finite-test uncertainty by

[stem]
++++
\widehat R=\frac1m\sum_{i=1}^{m}\ell_i,
\qquad
\widehat{\operatorname{SE}}(\widehat R)=\frac{s_\ell}{\sqrt m},
++++

only when the test units are independent. A block bootstrap is more appropriate for serially correlated air-quality observations.

== Worked example: exact fit versus coefficient stability

[.worked-example-context#worked-linear-context]
=== Context

*Importance:* Essential (P0)

An exact training fit is often presented as evidence that a linear model has solved the problem. This example separates residual fit, numerical coefficient stability, and future prediction by starting with an exact line and then introducing a nearly collinear design.

[.worked-example-method#worked-linear-method]
=== Method

*Importance:* Core (P1)

.Example: Exact line and residual error
[.examp#ex:exact-line]
****
For stem:[x=(0,1,2)] and stem:[y=(1,3,5)], use

[stem]
++++
X=\begin{bmatrix}1&0\\1&1\\1&2\end{bmatrix}.
++++

The vector stem:[\widehat\beta=(1,2)^\top] gives stem:[X\widehat\beta=y], so the residual norm and training RMSE are zero. This does not imply zero future error: three noiseless collinear points contain no evidence about curvature, changing noise, or a new population. If the last response becomes stem:[5.3], the fitted coefficient and residual uncertainty must be recomputed rather than treating stem:[(1,2)] as exact truth.
****

.Mathematical insight — conditioning controls coefficient sensitivity
[IMPORTANT]
====
[.notebook-insight-label]
*Mathematical insight.*

*Core (P1).* If stem:[X=U\Sigma V^\top], least squares divides data components by singular values. A small stem:[\sigma_{\min}] amplifies perturbations, and forming stem:[X^\top X] squares the 2-norm condition number: stem:[\kappa_2(X^\top X)=\kappa_2(X)^2]. Zero residual error therefore says nothing about coefficient stability. SVD-based least squares avoids the squared-conditioning computation but cannot create information in a weakly identified direction.
====

[.worked-example-implementation#worked-linear-implementation]
=== Implementation

*Importance:* Essential (P0)

The hand calculation is exact because the small design identifies its two coefficients. The executable extension changes one condition: it creates two nearly collinear predictors with known coefficients. It compares explicit normal-equation inversion, `numpy.linalg.lstsq`, and Ridge and reports coefficients, training RMSE, condition number, residuals, and singular values. Read the table before the figure: similar prediction errors need not imply stable coefficient estimates.

[#linear-conditioning-table]
[%dynamic%open,python,fail-on-error=,output=table,table-caption="Stable and unstable fits for a nearly collinear design",table-description="Rows compare an explicit normal-equation solve, singular-value least squares, and Ridge. Columns report two slope coefficients, training RMSE, and the design condition number."]
----
import numpy as np
import pandas as pd
from sklearn.linear_model import Ridge

# Fix the random generator so webpage and notebook evidence are reproducible.
rng = np.random.default_rng(20260722)
n = 250
x1 = rng.normal(size=n)
x2 = x1 + 1.0e-7 * rng.normal(size=n)
X = np.column_stack([np.ones(n), x1, x2])
y = 2.0 + 3.0 * x1 - 3.0 * x2 + 0.05 * rng.normal(size=n)


def rmse(beta: np.ndarray) -> float:
    """Compute training RMSE only for this numerical sensitivity experiment."""
    return float(np.sqrt(np.mean((y - X @ beta) ** 2)))


# The normal-equation solve is included as a diagnostic counterexample, not advice.
beta_normal = np.linalg.solve(X.T @ X, X.T @ y)
beta_lstsq, _, rank, singular_values = np.linalg.lstsq(X, y, rcond=None)
ridge = Ridge(alpha=1.0e-3, fit_intercept=False).fit(X, y)
condition = float(np.linalg.cond(X))
assert rank == X.shape[1]
assert condition > 1.0e6

fit_summary = pd.DataFrame(
    {
        "method": ["normal equations", "SVD least squares", "Ridge α=10⁻³"],
        "coefficient x1": [beta_normal[1], beta_lstsq[1], ridge.coef_[1]],
        "coefficient x2": [beta_normal[2], beta_lstsq[2], ridge.coef_[2]],
        "training RMSE": [rmse(beta_normal), rmse(beta_lstsq), rmse(ridge.coef_)],
        "κ₂(X)": [condition, condition, condition],
    }
).set_index("method")
fit_summary
----

Nearly cancelling coefficients are poorly identified even though predictions and RMSE can remain stable. Ridge changes the estimand by adding shrinkage; it is not merely a numerically clever way to obtain the unregularised coefficients.

=== Results

*Importance:* Essential (P0)

The exact three-point problem has zero residual norm, while the nearly collinear experiment has condition number above stem:[10^6]. The table shows that methods can have similar training RMSE but radically different individual slopes. The singular-value panel identifies the weak direction even when the residual panel appears unstructured.

[.worked-example-conclusion#worked-linear-conclusion]
=== Conclusion

*Importance:* Essential (P0)

An exact or low-RMSE fit does not establish stable coefficients or future predictive validity. RMSE checks agreement on observed responses, the residual plot challenges mean and variance structure, and the singular values diagnose coefficient sensitivity. Ridge changes the estimand through shrinkage rather than recovering the unstable unregularised coefficients. None of these diagnostics estimates performance on a new population; the generator fixes one noise law and one collinearity mechanism, so this is a numerical experiment rather than evidence that a real dataset obeys the Gaussian model.
