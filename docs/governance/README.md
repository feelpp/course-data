# Course governance

This directory contains the decisions that define the CSMI **Data Processing and Mining** course before content production begins.

The approved course baseline consists of:

- [Course decision record](decisions.md)
- [Baseline validation checklist](baseline-validation.md)
- [Course contract](course-contract.md)
- [Assessment blueprint](assessment-blueprint.md)
- [Dataset decision and shortlist](datasets.md)
- [`curriculum.yml`](../../curriculum.yml), the machine-readable outcomes, priorities, boundaries, and 28-hour schedule

Student-facing course-site content must be written in English. Changes to settled decisions require a dated amendment in the decision record and a corresponding change to `curriculum.yml` when applicable.
