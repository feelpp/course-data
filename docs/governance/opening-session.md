# Opening session — 7 September 2026

The public introduction has three linked pages: `starting-with-data.adoc`,
`csmi-connections.adoc`, and `data-in-action.adoc`. They are resources to revisit,
not a list of material to finish in one session. Allow time for students to describe
examples, discuss the figures, and explain a calculation in their own words.

| Minutes | Activity | Facilitation cue |
|---|---|---|
| 0–10 | Welcome and student examples | Explain why this course exists; collect two or three familiar examples of data. |
| 10–30 | Data origins and forms | Show the origins figure. Turn “22” into an observation with context. Let pairs identify source, representation and missing metadata. |
| 30–50 | Challenges, science and society | Discuss imperfect, massive and scarce data. Give time to examine the temperature table before showing its correction. Connect one processing choice to a scientific or societal consequence. |
| 50–60 | Break | Keep the simple temperature table available. |
| 60–75 | CSMI connections | Relate Database, Random Models, Scientific Computing and Project 1 to the example. Introduce the other links as future connections. |
| 75–100 | One pair audit | Use the two synthetic buildings: read the table, compare two questions, calculate, then explain. The station example is an optional transfer for later. |
| 100–110 | One application | Use Ktirio and one Lila Dayras figure to connect the classroom data question to research; another application can replace it. |
| 110–120 | Route, exit ticket and setup | Show the semester route and assessment guide briefly; collect three short answers and explain preparation for Block 2. |

Preparation and pacing:

- Open the three pages and keep the figures and small tables locally. The first
  session works with paper and a projector; no student installation is required.
- Pause after each figure. Ask students to describe what they see before supplying
  terminology; allow individual thinking, a pair exchange, then two explanations.
- Use one pair exercise thoroughly. Do not require both the building and station
  examples today. Treat silence as thinking time and rephrase when needed.
- Keep the first fifty minutes for the welcome and data foundations. CSMI links
  follow the break; the research example comes after students have practised.
- Project at most one application figure today. For Ktirio, use Lila Dayras's
  preprocessing slide 18 and keep the report's unit/category transformations
  (PDF pages 17–19) as a reference. The other five internships and all twelve PDF
  links remain on the applications page for later discussions.
- Keep specialised validation protocols, KDE, PCA and detailed physical models
  for subsequent sessions. Present the internships as end-of-M1 work.
- Introduce the live notebook in Block 2's first ten minutes, within its existing
  120-minute budget. Today's pair exercise can use the static pages throughout.
- If discussion needs longer, use the application slot for clarification and return
  to the research example later. Preserve the break and final practical guidance.
- Record aggregate exit-ticket themes and setup obstacles after class. The tools
  GitHub, Slack and Visual Studio Code will be addressed in Project 1 on 15 September.

This is a proposed facilitation schedule, not evidence that a class or human rehearsal
has already taken place. Adjust the pace to the students' explanations.
