# AI assistance log

If no AI assistance was used, state that explicitly with the date and assessment mode.

For every material use, record:

- date and tool/model/service;
- assessment mode and whether the use was permitted;
- task and a concise prompt summary without confidential, personal, examination, or hidden-test content;
- files or claims affected;
- suggestions accepted, changed, or rejected;
- independent verification: tests, primary documentation, derivation, experiment, or reviewer;
- remaining uncertainty and student responsible for the final decision.

Never paste secrets, personal/confidential data, current assessment material, solutions, or hidden tests into an external service.
